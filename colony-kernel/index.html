Why it matters

Multi-agent frameworks let the model drive workflow state — so the workflow is only as reliable as the model. Colony inverts the trust boundary: the model suggests, and an audited, deterministic core decides what is real. A model saying “this passed” is never the verification result — the kernel's gates are.

What it guarantees
🔒

Default-deny state machine

22 stages with a single-truth edge table — any transition not listed is illegal. Illegal transitions are refused, not warned about.

♻️

Apply-once event reducer

Accepted events carry a canonical hash, CAS version, and monotonic sequence. Replaying the log reconstructs identical state.

✍️

Content-addressed approvals

Approvals are SHA-256 over RFC 8785 JCS bytes, bound to the exact transition, consumed at most once, and expired at commit — so an approval can't be forged or replayed.

💰

Budget ledger

Immutable limits with CAS rows. Agents can't mint resources or top themselves up.

🧱

Deny-by-default roles

No self-mutation, no publication by default; reserved public states are unreachable unless explicitly enabled.

🧾

Durable rejections

A refused command leaves evidence and never mutates state — refusals are auditable, not silent.

Run it yourself
  1. Clone and install: git clone https://github.com/faresrafat3/colony-kernel && cd colony-kernel && npm install
  2. Verify everything: npm run verify — typecheck, lint, 67 tests, byte-identical demo.
  3. Prove determinism: npm run demo > a.json twice, then diff a.json b.json — no output.
